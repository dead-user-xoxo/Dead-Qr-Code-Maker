This is A simple, native macOS app that turns any website into a QR code.

It works by typing a website URL and press enter then the app checks that the site is live then it creates a QR code you can copy, save, share, or drag into any app.

Features!

- **Live website check**: makes sure the URL works before creating the code (can be turned off in Settings)
- **Custom colours**: choose the code and background colours, with a warning if the code may not scan
- **Export as PNG or SVG**: PNG up to 4096 × 4096 px, or a vector SVG for print
- **Copy, Share and Drag & Drop**: put the code straight into Messages, Mail, Finder, Pages and more
- **History**: reopen recently made QR codes
- **Error correction levels**: Low, Medium, Quartile or High
- **Light and Dark Mode**: follows your system appearance and accent colour
- **Keyboard shortcuts** for everything
- Universal app: runs natively on Apple Silicon and Intel Macs

Requirements

macOS 13 Ventura or later

Installation

1. Download QR Code Maker.dmg from the Release page.
2. Open the DMG and drag QR Code Maker into your Applications folder.
3. Open the app.


How to fix the "Apple could not verify…" message

This app isn't notarised by Apple, so macOS blocks it the first time you open it. To allow it:

1. Try to open the app, then click Done on the warning.
2. Open System Settings → Privacy & Security.
3. Scroll down and click Open Anyway next to QR Code Maker then confirm.

You only need to do this once!


Privacy

- No accounts, no tracking, no analytics.
- The only network request is the check that the website you entered is live.
- Settings and history are stored only on your Mac in `~/Library/Application Support/QR Code Maker/
